# Hi, I'm Mark

I like fixing things: software, old phones, slow PCs. I build small, careful tools and share them as open source. Based in Bangalore, India.

Most of what's here started as something that annoyed me at home, so each tool is meant to be usable by someone who is not a programmer: plain English, no account, no cloud unless it truly needs one.

## For your PC

- **[WinVitals](https://github.com/mark-alexander-hub/winvitals)**: diagnose, clean up and speed up a Windows PC, in plain English. `winget install winvitals`
- **[salvage](https://github.com/mark-alexander-hub/salvage)**: careful, resumable data recovery for damaged discs, hard disks, USB sticks, memory cards and Android phones. It only ever reads.
- **[Router Doctor](https://github.com/mark-alexander-hub/router-doctor)**: a read-only check-up for your home Wi-Fi and router. One double-click, no install.
- **[Toby](https://github.com/mark-alexander-hub/toby-desktop-companion)**: a desktop companion that lives on the taskbar, talks, and reminds you to take breaks.

## For your phone

- **[Home Sense](https://github.com/mark-alexander-hub/home-sense)**: three home tools from your phone's own sensors: a Wi-Fi signal floor plan that draws itself, a metal finder for walls before you drill, and a mosquito radar. No internet permission.
- **[Spare Eye](https://github.com/mark-alexander-hub/spare-eye)**: turns a spare Android phone into a home camera that messages you on Telegram when something moves. No account, no cloud.
- **[Honk Orchestra](https://github.com/mark-alexander-hub/honk-orchestra)**: turns street horns, whistles and chirps into music, live. [Try it in the browser](https://mark-alexander-hub.github.io/honk-orchestra/).

## For people

- **[Jodi](https://github.com/mark-alexander-hub/jodi)**: a free, private singles' corner for one wedding. Guests scan a QR code; contact details are shared only when two people like each other. In English, Hindi, Kannada and Tamil. [weddingjodi.pages.dev](https://weddingjodi.pages.dev)
- **[Polyglot DSA](https://github.com/mark-alexander-hub/polyglot-dsa)**: learn data structures in your own language (English, Hindi, Kannada, Tamil, Sanskrit) with the same code in Python, C++, Java and JavaScript. [Open the site](https://mark-alexander-hub.github.io/polyglot-dsa/)

## Contributing elsewhere

- **[open-headunit](https://github.com/andreknieriem/open-headunit)**: Android Auto on any Android screen. I run it in my 2012 Ford Figo and send fixes upstream.
